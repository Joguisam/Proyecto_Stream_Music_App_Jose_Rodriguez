# 🎵 Kaleidoscope Music - Marketplace

Bienvenido a **Kaleidoscope Music**, una plataforma web diseñada para la compra y venta de música independiente. Este proyecto es una vitrina digital que busca conectar a artistas con oyentes de todo el mundo a través de una interfaz colorida y moderna.

## 🚀 Descripción
Este es un proyecto enfocado en el desarrollo **Frontend**, donde se prioriza la estructura semántica y el diseño visual responsivo. El objetivo es simular la experiencia de un marketplace de música real.

## 🛠️ Tecnologías utilizadas
Para este proyecto se han utilizado únicamente tecnologías web estándar:

* **HTML5:** Para una estructura semántica clara (headers, sections, articles, footers).
* **CSS3:** Para el diseño, colores, tipografías y el sistema de rejillas (Flexbox/Grid).

## 📁 Estructura del Proyecto
El repositorio está organizado de la siguiente manera:

- `index.html`          # Página principal del marketplace.
- `css/`                # Carpeta contenedora de estilos.
  - `styles.css`        # Hoja de estilos principal.
- `assets/`             # Imágenes, iconos y recursos visuales.
- `README.md`           # Documentación del proyecto.

## 💻 Cómo visualizar el proyecto
1. Clona este repositorio o descarga los archivos.
2. Localiza el archivo `index.html` en la carpeta raíz.
3. Haz doble clic sobre él o arrástralo a tu navegador favorito (Chrome, Firefox, Edge).
